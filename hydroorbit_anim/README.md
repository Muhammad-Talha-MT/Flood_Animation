# HydroORBIT booth animation: Douglas Reservoir, French Broad River (Feb 22-24, 2019 event)

54.5 s, 1920x1080, 30 fps. Opens on the contiguous US, zooms to the Tennessee River Basin and then to the drainage
above Douglas Dam, plays one storm with the HydroORBIT AI and TVA forecasts at USGS 03455000 (French Broad near
Newport, TN), and pulls back out to the US.

## Setup

```
python -m venv ../.venv && ../.venv/bin/pip install -r requirements.txt
sudo apt-get install libosmesa6 libegl1 libgl1 fonts-inter p7zip-full     # headless VTK, Inter font, .7z archives
```

Fonts are read from `/usr/share/fonts/opentype/inter/`.

## Not in this repository (private)

* `Vinh_data/03455000_forecasts_2016_2025.nc`: forecasts and observations for USGS 03455000 (variables
  `observed_Q`, `observed_Pr`, `TVA_Q`, `AI_Q10/50/90`, 6-hourly leads 6-48 h). Unpublished model output shared by
  Vinh. Put the file at that path before running `hydro.py`.
* `private/` and the finished `out/hydroorbit_booth_v6.mp4`: frames, contact sheets, `hydrograph_data.csv` and the video show Vinh's forecast curves.
* `data/` (about 1.7 GB) and `build/`: regenerated by `fetch.py`, `prep.py`, `prep_conus.py`, `hydro.py`.

## Run order

```
python fetch.py                  # data/: WBD, NHDPlusV2 VPU 06, NID dams, 3DEP, USGS gauge and 6-h flow record
python prep.py                   # build/: grids, textures, D8 routing, river polylines, dams, sanity_map.png
python prep_conus.py             # build/conus.npz: static CONUS map for the opening
python hydro.py                  # build/hydro.npz, data/rain_grid_*.npz, private/hydrograph_data.csv
python render.py --stills 3,12,27,50      # PNGs in private/stills/ (video seconds)
./run_render.sh                  # out/hydroorbit_booth_v6.mp4, resumable in 150-frame chunks
```

`fetch.py` needs the NHDPlusV2 archives extracted into `data/nhdplus06/` first (commands are in a comment in the
script). Render one chunk at a time (`JOBS=1`, the default): two renderers run out of memory on 8 GB. If the render
stops, run `./run_render.sh` again; finished chunks (`build/chunks/*.done`) are skipped. Delete `build/chunks/` after
any change to the picture, or stale chunks will be joined into the new video.

## What is real and what is illustrative

| Element | Source |
|---|---|
| US map | USGS small-scale streams (1:1M, Strahler order >= 4), Census state boundaries |
| Tennessee basin, Douglas drainage | USGS WBD HU2 06; union of NHDPlusV2 catchments above Douglas Dam (11,753 km2) |
| Rivers, lakes | NHDPlusV2 flowlines and waterbodies |
| Hydropower dams | USACE National Inventory of Dams (hydroelectric purpose, one point per project) |
| Terrain | USGS 3DEP (120 m basin, 60 m Douglas drainage), 4-10x vertical exaggeration |
| Observed streamflow and rain | Vinh's file: 6-hour mean flow at USGS 03455000 and 6-hour basin rain |
| HydroORBIT AI median, 10-90 % range, TVA forecast | Vinh's file, forecast issued 2019-02-22 06:00 UTC (48 h before the peak) |
| Median and moderate flood levels | USGS record at 03455000, 6-h annual maxima, water years 2008-2025 (median annual peak; 5-year flood, lognormal fit without 2024) |
| Chance of flooding chips | Lognormal fit to the AI 10/50/90 % values at the forecast peak. Derived here, not model output |
| River glow, particles | Routing model (SCS-CN, translation along NHDPlus flow distance) fitted to the observed flow at the gauge |
| Rain pattern across the map | Stylised moving field whose basin mean equals the observed rain each hour (no gridded rain exists before 2020-10-14) |

Time convention assumed: Vinh's times are UTC and each 6-hour value covers the window ending at its time.
